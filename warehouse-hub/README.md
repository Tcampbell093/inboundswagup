# Warehouse Operations Hub

Team-facing operations launcher and bulletin-board view.

This staging build includes:
- Today / Week dot-switch views
- Shared cleaning assignments and completion status
- Announcements and policy updates
- Manager publishing controls
- Associate PIN-based cleaning check-in
- FairShift sync endpoint for future direct schedule integration

Staging is the validation environment. Do not seed production employee data until access and rollout boundaries are approved.
